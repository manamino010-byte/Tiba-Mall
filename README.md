# 🚗 أوتو بارتس — فرع طيبة جراند مول
## موقع عرض معلوماتي | وسط البلد، 6 أكتوبر

---

## 📋 نظرة عامة

موقع Portfolio بسيط واحترافي يعرض فرع أوتو بارتس داخل مشروع "وسط البلد" التجاري الإداري الطبي، 6 أكتوبر. مصمم لعرض المعلومات بشكل محايد وواضح لأصحاب القرار.

---

## ✅ الميزات المنجزة

- **Hero Section** — صورة كاملة الشاشة + إحصائيات بارزة (السعر، المساحة، رقم الوحدة) + زرين للتنقل
- **تفاصيل الفرع** — بطاقات معلومات منظمة + وصف واقعي + حساب سعر المتر
- **الموقع والمحيط** — خريطة Google Maps + جدول مقارنة أسعار الوحدات + صور جداول الأسعار من PDF الرسمي
- **معرض الصور** — 5 صور (واجهة، داخل×2، مخزن، المنطقة المحيطة) مع تصفية بالفئة + Lightbox كامل الميزات
- **Navbar** — ثابت في الأعلى مع تأثير scroll + قائمة موبايل
- **Scroll Reveal** — ظهور سلس عند التمرير
- **Back to Top** — زر للعودة لأعلى الصفحة
- **Lightbox** — تكبير الصور + تنقل بالأسهم + keyboard + swipe للموبايل
- **Footer** — بيانات الشركة والموقع
